# Movie Review Sentiment Analysis

## Project Description

This project uses Deep Learning and Transfer
Learning to classify movie reviews as Positive
or Negative.

## Pretrained Model

DistilBERT

## Dataset

IMDb 50K Movie Reviews Dataset from Kaggle.

## Technologies Used

- Python
- Google Colab
- Hugging Face
- DistilBERT
- Streamlit
- GitHub

## Features

- Enter movie reviews.
- Predict positive or negative sentiment.
- Display prediction confidence.

## Application

Developed using Streamlit.
